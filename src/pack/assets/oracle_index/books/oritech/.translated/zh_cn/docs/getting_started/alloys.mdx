手工合成仅适用于最初几台机器。但应尽快将合金生产转入[Pulverizer](@oritech:pulverizer_block)加[Foundry](@oritech:foundry_block)的组合配置中。

这一转变是奥瑞科技早期发展过程中最重要的效率升级之一，同时也为你后续冶炼有机钢、Energite及昶铂等合金奠定基础。
