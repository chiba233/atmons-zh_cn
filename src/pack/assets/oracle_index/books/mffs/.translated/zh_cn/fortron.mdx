# Fortron

Fortron 是一种能量形态，MFFS 的机器靠它供能。它由 [Fortron 衍生器](@mffs:coercion_deriver) 产生并初步储存，再由
[Fortron 能量储存器](@mffs:fortron_capacitor) 转送给其他机器。

Fortron 还有另一个来源：创造模式专属的无限能量卡。把它直接放进 [Fortron 能量储存器](@mffs:fortron_capacitor)（最左边那个物品格），
就能提供源源不断的 Fortron。

Fortron 可以以液体形态存在。它能直接从 [储存器](@mffs:fortron_capacitor) 里抽出来，
像 [水](@water) 或 [岩浆](@lava) 一样处理。
