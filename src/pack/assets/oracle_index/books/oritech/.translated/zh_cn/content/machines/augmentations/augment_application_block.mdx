这些改造可提供各类增益，范围涵盖被动属性提升至全新能力解锁。

# 研发

首先，请走入已组装完成的**赛博改造中心**。
此举将打开研究界面，您可在其中浏览并启动各项研究项目。
每项改造均需消耗特定能量与资源，这些资源可来自您的个人物品栏，
或机器内部存储（可通过界面访问）。


许多高级升级需要先完成前置研究，具体参见科技树。

中心单元作为**研究站**的枢纽，以多区块插件形式构建。主单元最多支持**三座研究站**，实现并行处理。
*   每个站点均需**3个机器核心**。
*   一座车站一次仅能处理一项活跃的研究任务。

# 应用与控制

研究完成后，改造项目即可安装。安装过程需一次性消耗资源，以永久将该技术融合至玩家体内。

若已安装赛博改造件，可使用**导入**功能（界面左下角按钮）将其载入机器。

**增强管理**：
您的增强效果设计为永久生效：无需维护或持续消耗能量。
但若某项能力（如**矿石感应**或**超速加工**）造成干扰，您可随时开关切换。

*   **切换菜单**: 按下强化快捷键（默认为**[G]**）以打开环形界面。将光标悬停于期望
增强并释放以切换其状态。
*   **移除**: 尽管强化效果本意为永久性，但在必要时仍可移除。
请注意，投入安装设施的资源不可退还。

**整合包开发者须知**


Oritech增强功能完全基于数据驱动且可配置，支持通过数据包进行深度自定义。

*   **修饰增强件**: 修改实体属性（例如速度、攻击范围、生命值）。
*   **效果增强件**: 施加与药水类似的状态效果。
*   **自定义增强**: 实现独特逻辑（例如：矿物透视）。这些逻辑可在数据包中引用，但需Java模组支持
底层逻辑所依赖的模组。

现有增强符文可被修改或禁用，亦可通过JSON定义全新符文。
*   **示例定义**: [攻击伤害增强 (GitHub)](https://github.com/Rearth/Oritech/blob/1.21/fabric/src/main/generated/data/oritech/recipe/augment/attackdamage.json)
*   **材质位置**: `oritech/textures/gui/augment`

请务必为所有自定义新增内容添加翻译条目。
