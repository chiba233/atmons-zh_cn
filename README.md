All the Mons 的简体中文汉化补丁，对应整合包 **1.2.0**。
整理／补译：**星野夢華 (Hoshino Yumeka)**。

> **装这一个就够。** 本包是**完整的一份汉化**，不是叠在别家之上的补充包：语言文件 10.8 万余条、
> 任务书、15 个模组的导览书、字节码硬编码文本、204 张烤进 PNG 的艺术字都在里面（见[汉化范围](#汉化范围)）。
> **不需要**先装其他汉化当前置——同时装两份会互相覆盖。整合包装好后直接装本包即可。

## 兼容版本

| 整合包版本 | Minecraft | NeoForge |
|---|---|---|
| All the Mons **1.2.0** | 1.21.1 | 21.1.248 |

只做这一个版本。整合包升级会改动英文原文，同一份译文通吃会让玩家读到一段通顺却对不上自己那版的中文——
比漏翻更难发现。整合包出新版时本包另行重新核验后发布。

## 汉化范围

整合包内共 **398 个模组 jar**，其中 **200 个命名空间自带官方中文**，本包不做重复翻译。
工作集中在三类位置：**语言文件够不着的**（烤进 PNG 的美术字、字节码常量、界面描述文件）、
**条目量大而长期无人处理的**（结构名、家具、配置项一类的长尾）、
**已有中文但不一致或有错的**（同一事物在任务书与物品栏里叫法不同）。

| 范围 | 内容 |
|---|---|
| 语言文件层 | 出货 **306 个语言文件、10.8 万余条**。其中 **132 个模组游戏内的中文完全依赖本包**（官方 jar 一条中文都不带），另有 **165 个模组**在官方基础上补齐了缺翻的键 |
| 宝可梦一系 | Cobblemon 及其附属是本包的主体：宝可梦百科、超级对决、团体战巢穴、战利品球、牧场打工、家具、导航、石像、对战塔等。宝可梦、招式、道具、地名、人名一律取**官方中文**（52poke 收录的任天堂译名），不自拟：道馆馆主与四天王用阿李、竹兰、菊子、瓢太、菜种；银河队干部用伙星、岁星、镇星；地名用喇叭芽之塔、烧焦塔、烟墨市、归途洞窟、心齐湖、海紫堇 |
| 任务书（FTB Quests） | **9,169 条**，覆盖上游 78 个章节文件。术语以**物品栏里的真名**为单一真源逐条对齐——照任务书所述名字在 JEI 里搜不到东西，是危害最大的一类缺陷 |
| 任务书图片艺术字 | 重绘 **204 张**把标题烤进 PNG 的图片。文字取自该章节已有的中文标题，保证图片、章节名、任务名三处写法一致；配色自原图逐行采样；含装饰的图只替换文字区域，边界按连通域算出，一旦侵入装饰即报错终止 |
| 模组导览书 | **15 个模组、813 个条目**：气动工艺 231、RFTools 基础 103、极限反应堆 86、资源蜜蜂 81、工业先锋 80、模块化路由器 61、神谕目录 44、铁路 42、激光 IO 40、全能魔金 19、高效树木 13 等。手册是流程受阻最集中的位置 |
| 字节码硬编码文本 | **156 个模块**，指没有翻译键、固化在 class 常量池里的界面文本。每次构建都对着**该版真实字节码**核验命中率，未命中的如实记录，不计入有效覆盖 |
| RFTools / XNet 全系 | 该系模组的界面不经语言文件渲染，每个界面由一个 `.gui` 文件描述。本包重写 **24 个 `.gui`**，再以字节码补丁补足模式选项与提示。**枚举协议值一律保持英文**——它们是存档与网络协议里的实际取值，译了会崩，CI 设有硬性检查 |
| 主菜单首页 | 重绘 **10 个按钮**（每个含常态与高亮两张，共 20 张）：单人游戏 / 多人游戏 / 选项 / 退出 / 模组 / 语言 / 租用服务器，另加「汉化包主页」「问题反馈」「GitHub」三个 |
| 结构名 | 整合包内 **304 个结构**全部有中文，探险指南针与传送门列表里不再有英文。此处未汉化时只能拿英文检索，而它是使用频率最高的搜索入口之一 |

各项均有机械校验兜底：物品名与任务书的一致性、任务书断行与块结构、`.gui` 与字节码命中率、
须保持英文的清单、译文占位符与英文原文是否对得上，各设一道 CI 闸，未通过即无法发布。
清单与做法见 [CONTRIBUTING.md](CONTRIBUTING.md)。

## 我该下载哪个包？

**客户端请下载文件名含 `client` 的，含 `server` 的是开服的人才需要。**

[Releases](../../releases) 里有两个文件：

| 文件 | 装在哪 | 谁需要 |
|---|---|---|
| `atmons-zh_cn-client-<补丁版本>-mons<整合包版本>.zip` | **你自己电脑上的 All the Mons 实例** | **所有人都要装。** 单人玩家只装这一个就够 |
| `atmons-zh_cn-server-<补丁版本>-mons<整合包版本>.zip` | **服务器**（开服那台机器 / 面板） | 只有**开服的人**要装 |

文件名里两个版本号含义不同：`r1` 之类是**补丁自己的版本**，`mons1.2.0` 才是**你的整合包版本**。

### 「我玩单人，两个都要装吗？」

**不用，只装客户端包。** 单人模式下 Minecraft 在你自己的进程里跑了一个内置服务端，
用的就是你客户端的中文，所以「由服务端生成」的文本（任务书正文等）在单人下天然是中文。

⚠️ **反过来别做**：不要把客户端包丢到服务器上。

## 客户端安装

### 第 1 步：找到实例文件夹

就是**含 `mods` 文件夹和 `options.txt` 的那一层**。CurseForge / Prism / HMCL 里右键实例 →
「打开文件夹」。常见路径形如 `...\.minecraft\versions\All the Mons\`。

### 第 2 步：解压，把**整个文件夹**放进去

解压后会得到一个名叫 `atmons-zh_cn-client` 的文件夹，**整个拖进实例目录**：

```
All the Mons\             ← 实例根目录
├─ mods\
├─ options.txt
└─ atmons-zh_cn-client\   ← 刚放进来的
   ├─ 双击安装-Windows.bat
   ├─ install.sh
   └─ ...
```

放错地方也没关系，安装器会提示你手动输入实例路径。

| 装法 | 怎么做 | 结果 |
|---|---|---|
| **A. 推荐** | 把解压出的**整个文件夹**放进实例目录，再运行里面的安装器 | 安装器先备份原文件再覆盖，随时可一键回退 |
| **B. 就地解压** | 直接把压缩包**内容**解压到实例根目录当场覆盖 | 汉化确实生效，但**原文件在解压那一刻就被盖掉了，没有备份** |

### 第 3 步：运行安装器

- **Windows**：双击 `双击安装-Windows.bat`
- **macOS / Linux**：在该文件夹里终端运行 `bash install.sh`

选 **[1] 应用汉化**。安装器会备份将被覆盖的原文件到 `backups/<时间戳>/`、复制汉化文件、
并在 `options.txt` 里启用汉化资源包。

### 第 4 步：确认装上了

进游戏，主菜单按钮应该是中文。任务书打开后章节名与标题图都应是中文。

### 卸载 / 回退

再运行一次安装器，选 **[3] 恢复备份**，回到安装前的状态。

## 服务端安装

**只有开服的人需要。单人玩家跳过。**

下载 `atmons-zh_cn-server-…` 解压，按包内 `请安装前务必看我.md` 覆盖到服务器目录后重启服务端。
它带的东西很少，都是**必须由服务端产出**的文本：

| 内容 | 为什么必须在服务端 |
|---|---|
| `config/ftbquests/` 任务书语言 | 任务书数据由服务端下发给所有玩家 |
| `kubejs/server_scripts/` 与 `kubejs/data/` | 由服务端执行、下发的那部分文本 |
| `mods/vaultpatcher.jar` + 服务端模块子集 | 服务端生成的那些字符串 |

详见 [SERVER.md](SERVER.md)。

## 已知限制

- **9 条专有名词保持英文**：画作署名 PKMNCC / Gootastic、模型作者 LostMyself / TedXenon、
  地图模组名 BlueMap。这些是人名与品牌，本就不该译。
- **蘑菇与作物的拉丁学名保持拉丁文**：`Tuber melanosporum` 这类字段是学名，不是描述。
- **Borrius 地区名是自主命名**：译作「波留斯」。这是 Pokémon Unbound 改版自造的地区，
  mcmod、52poke 与中文改版社区都查不到译名，按「都没有才可自主命名」处理。
- **天境模组内置的「物品能力提示」资源包未汉化**：那 137 条躺在 jar 内的一个可选资源包里，
  整合包默认没有启用它，装不装本包都不显示。
- **Borrius 阵营的自创角色保持英文**：Alice、Jax、Marlon、Milo、Penny、Zeph 等 20 余个名字
  是这个模组自造的，52poke 上查不到；同名于官方的西子伊、亚洛的那两个也**不能**套官方译名。
