---
title: 矿石破碎
icon: oritech:platinum_clump
---

一台[粉碎工厂](../processing/fragment_forge)可提升矿物产出率。当在粉碎工厂中加工矿物时，其将被分解为矿石块及小型矿石块。

九个小矿团可合成一个矿团，矿团可送入[centrifugeuse](../processing/centrifuge)中转化为粉尘与微尘，进而于熔炉中冶炼。


您可将原生矿石投入粉碎工厂，但对某些矿石而言，若使用附魔“精准采集”的镐挖掘矿石方块后再投入粉碎工厂，效果更佳。

粉碎工厂与离心机亦可产出次级矿物。例如，加工[nickel](../resources/nickel)将得到镍，同时还可能产出少量[platine](../resources/platinum)。
