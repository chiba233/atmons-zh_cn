Oracle索引还具备一项功能：内容需先解锁，玩家方可访问。锁定页面将以模糊方式呈现，且不会出现在搜索结果中。
若某文件夹下所有条目均被锁定，则整个文件夹将被隐藏。

<Callout variant="warning">
    这项功能显然只在游戏内 wiki 里可用，线上 wiki 没有。主要面向的是不想一次性把内容全部揭晓的整合包作者。
</Callout>

要控制解锁条件，页面的前置元数据需包含*unlock*部分。其格式如下所示：

```
---
title: 游戏内模组视图配置
unlock: advancement:minecraft:oritech/pulverizer
---
"unlock" 恒定不变
"advancement" 是进度校验器的名字
"advancement:" 之后的内容会原样传给校验器
```

# 验证器
模组开发者可向**Oracle进度API**注册自定义验证器。更多详情请参阅该API类的Javadoc文档。

Oracle索引不会存储哪些条目已被解锁，而是按需调用验证器。

## 成就验证器
默认情况下，模组仅包含一个验证器：进度验证器。它会检查玩家是否已完成特定成就，以决定是否允许其查看页面。
