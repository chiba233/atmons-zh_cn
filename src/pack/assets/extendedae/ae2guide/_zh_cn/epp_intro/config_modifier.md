# 配置修改器

配置修改器是一种用于批量修改配置容器的工具。

<ItemImage id="extendedae:config_modifier" scale="4"></ItemImage>

右键点击它即可打开其 GUI。

## 用法

配置修改器可以根据其设置快速修改诸如接口配置容器之类的内容，例如将配置物品的
数量设为最大值，或直接全部移除。

你可以手持配置修改器在世界中点击目标设备（方块或部件）来修改其配置。

## 设置

它有两个主要设置：**修改模式**和**修改数量（X）**。

你可以点击按钮来切换模式。

![GUI](../pic/cm.png)

- 加/减/乘/除：将配置数量按 X 进行加/减/乘/除。
- 最大化：将配置数量设为最大值。
- 最小化：将配置数量设为最小值。
- 设定：将配置数量设为 X。
- 清除：清空全部配置。
