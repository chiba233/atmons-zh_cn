# AE2扩展 的起点

<Row>
<BlockImage id="extendedae:machine_frame" scale="8"></BlockImage>
</Row>

收集到足够的 <ItemLink id="extendedae:entro_crystal" /> 后，你终于可以制作第一个扩展机器框架了。
这些框架是 AE2扩展 的基础，大多数 AE2扩展 中的方块形式机器都需要它们。
