此时你已拥有向外拓展所需的核心部件。

接下来的良好方向包括：
- 构建更清洁的物流与能量网络。
- 拓展至龙门式自动化及基于机器框架的农场。
- 投资于[multiblocks]($MULTIBLOCKS)和[addons]($ADDON_CONCEPTS)。
- 向[核反应堆]($NUCLEAR_REACTOR)或[粒子加速器]($PARTICLE_ACCELERATOR)迈进。
- 待资源流稳定后，即可启动赛博格增强研究。

继续浏览手册其余部分，选定发展方向，开始专业化建设你的工厂。
