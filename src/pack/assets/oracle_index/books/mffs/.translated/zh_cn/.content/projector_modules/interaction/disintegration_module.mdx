# 分解模块

分解模块可以装在 [力场投影仪](@mffs:projector) 上，改变力场对周围环境的作用。
把分解模块放进投影仪的矩阵槽后，它生成的力场会破坏挡路的方块。被破坏的方块会掉落成物品，可以捡起来。

<PrefabObtaining />

## 用法

分解模块与所有投影模式都兼容，可以用来把 [稳定模块](mffs:stabilization_module) 的效果反过来用。
在投影仪里加入 [速度模块](@mffs:speed_module)，可以同时分解多个方块。
它也能与 [收集模块](@mffs:collection_module) 搭配，自动捡起被破坏的方块。
