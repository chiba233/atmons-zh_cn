# 干涉矩阵

干涉矩阵是 MFFS 机器家族的一员。

它对周围空间里的玩家或实体施加限制。比如可以配置成自动杀死进入作用范围的怪物或玩家，
或者阻止未授权的玩家动其他机器。

<PrefabObtaining />

## 运作方式

干涉矩阵周围的空间在逻辑上分成两层：**作用区**与**警告区**。

作用区从矩阵本身向外延伸，格数等于装入的 [扩展模块](@mffs:scale_module) 数量。
警告区默认从作用区边缘再向外延伸 3 格，是一个同心球壳。

玩家进入干涉矩阵的警告区时，会收到一条提示，告知他刚刚进入了扫描范围。
如果不想亲身体验矩阵装了哪些模块，就别再往里走。

不装任何模块的干涉矩阵其实什么都不做；装上模块之后，它可以成为一套强力的防御系统。
