你需要先收集一些基础资源才能开始。

首先寻找[矿石岩层](../resources/ore_boulder)或开始挖掘。您将需要铜、铁、煤炭与[niklu](../resources/nickel)。

所有奥瑞科技（Oritech）矿石的生成方式均类似于普通洞穴矿石。镍矿石分布于Y=40至Y=-65区间。铂矿石在主世界Y=-2至Y=-60区间较为稀有，
但在末地维度则储量丰富。

黄金、红石以及若干钻石也很快会派上用场，请务必一并收集。
