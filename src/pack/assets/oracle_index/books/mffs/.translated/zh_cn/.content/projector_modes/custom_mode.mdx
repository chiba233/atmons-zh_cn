# 自定义模式

自定义模式是所有模式里最灵活的一个：它能投射出任意形状、任意结构的力场。
只要自定义模式物品分析并存下了玩家指定的方块图样，[投影仪](@mffs:projector) 就能生成一个与原物一模一样的力场。
换句话说，凡是能搭出来的东西——桥、房子、乃至整座要塞——都能做成力场。

<PrefabObtaining />

## 用法

手持自定义模式物品，对世界里的两个方块使用。这两个方块（第一点与第二点）框定出一个可供分析的三维空间。
每点一个方块，它的坐标就会被记为「第一个点」和「第二个点」。潜行使用，即可让自定义模式物品分析并保存
两点之间的全部方块。

当投影仪检测到正确槽位里放了自定义模式物品时，它上方会不断随机冒出全息影像，
表示这个力场图样与任何已知模式形状都对不上（这是特性，不是 bug）。
如果需要，可以把 [位移模块](@mffs:translation_module) 放进带方向箭头的槽位，
来设定力场相对投影仪出现在什么位置。

## 形状调整

和其他投影模式一样，自定义模式的力场也能用 [旋转模块](@mffs:rotation_module) 和
[扩展模块](@mffs:scale_module) 来旋转和放大。
