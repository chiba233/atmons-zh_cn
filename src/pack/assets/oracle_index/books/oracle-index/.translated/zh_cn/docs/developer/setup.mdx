本页面面向希望其Wiki内容可通过Oracle Index模组在游戏中访问的开发者。

## 项目设置
1. 按照moddedmc.wiki的说明，正常创建你的wiki目录/内容布局
2. 确保你为**所有**内容都配备了_meta.json文件。Oracle索引使用meta.json文件构建导航栏。
3. 将整个wiki复制到你的mods资源文件夹中。此操作可自动化，详见[auto gradle sync](../developer/gradle_task)。正确路径为："resources/assets/oracle_index/books/your-mod-id/"。
5. Oracle索引将自动加载你模组的资源。

不支持热重载。请使用moddedmc.wiki实时预览功能来创建您的Wiki内容。不过资源重载仍可刷新游戏内内容。

游戏内wiki资源可通过资源包（亦可内置于模组中）添加。请参阅oritech仓库，了解具体设置方法。

### 局限
Oracle索引仅包含一个基础Markdown解析器。这意味着大多数HTML标签均不被支持。
大部分Markdown功能（如标题、粗体、斜体、页面间链接等）均受支持。部分moddedmc专用HTML标签（如"ModAsset"、"Callout"或"CraftingRecipe"）也受支持。不支持的HTML标签将被忽略，且完全不会显示。

若您希望使用其他HTML标签，欢迎提交PR。

若`<ModAsset>`（或物品资源）图像与现有游戏内物品匹配，则将直接显示实际的游戏内物品（或方块物品），因此你无需包含物品的渲染贴图。
所有图像均应位于".assets/modid/"文件夹中，而非".assets/item/modid"子文件夹。内容wiki的物品属性将从游戏内注册表中收集，而非使用预定义的json文件。

若段落中存在你不希望在游戏内wiki中显示的内容（例如表格或其他不受支持的元素），可将该段落包裹在如下div标签中：
`<div onlineOnly="true" >`

### 物品链接
Oracle索引新增的一项功能是为wiki页面关联相关物品。为此，需在mdx前置数据中新增一个参数："related_items"，其值为一个游戏内物品ID数组。其格式如下所示：
```
---
title: Generators
icon: oritech:basic_generator_block
related_items: [oritech:basic_generator_block, oritech:bio_generator_block, oritech:lava_generator_block, oritech:fuel_generator_block, oritech:big_solar_panel_block]
---
这里放你自己的内容。
```

这些链接将自动为内容维基条目生成。

### 自定义书本 / 打开界面
Oracle索引默认不附带指南书。然而，在你的模组中，你只需轻松添加一个新的书籍物品，并在玩家使用该书时打开指定界面即可。
你还可以通过其他机制（如另一界面中的按钮）来打开该书。

请在客户端执行以下代码：
```
// 这里的 Oritech 是 wiki 的名字。
// 第二个参数是要打开的条目。命名空间恒为 "oracle_index"
OracleClient.openScreen("oritech", "oracle_index:books/oritech/intro.mdx");
```
