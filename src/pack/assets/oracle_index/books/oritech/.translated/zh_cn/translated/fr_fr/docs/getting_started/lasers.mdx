title: 激光！
icon: oritech:laser_arm_block
---

在继续推进前，您需要[fluxite](../resources/fluxite)。要获取它，请使用[末影激光器](../interaction/enderic_laser)过载紫水晶簇。

制造工艺依赖前述所有步骤，需结合合金、组装部件，以及某些特定物品（例如[末影化合物](../resources/enderic_compound)与碳纤维）。


使用[目标标识器](../tools/target_designator)和[发电机](../processing/generators)，您即可开始生产通量水晶。
