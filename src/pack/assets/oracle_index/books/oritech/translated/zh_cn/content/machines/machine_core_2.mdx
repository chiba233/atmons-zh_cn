机器核心决定奥瑞科技多区块机器的品质。更高级的核心并不会自动提升机器速度。其主要作用在于提升机器可支持的延伸器及关联插件层数。

**合成**
- 机器核心按等级合成，每一等级均提升品质上限。
- 第一级使用木板与工作台。
- 二级需使用铜或铁配合青金石。
- 第三等级使用[碳纤维](@oritech:carbon_fibre_strands)或[镍](@oritech:nickel_ingot)配合红石。
- 第四等级使用[机器护板方块](@oritech:machine_plating_block)与[末影复合物](@oritech:enderic_compound)。
- 第五等级使用 [精镍锭](@oritech:adamant_ingot)与[高级计算引擎](@oritech:advanced_computing_engine)。
- 第6级使用[昶铂](@oritech:duratium_ingot)与[可疑容器](@oritech:dubios_container)。
- 第7级使用[钷](@oritech:promethium_ingot)与[超导体](@oritech:superconductor)。

**用法**
- 多方块机器在右键点击时会高亮显示其所需的核心位置。
- 你还可以手持核心右键点击机器，只要目标位置无障碍物，即可自动安装下一个有效的核心。
- 最终机器品质决定扩展器深度与插件缩放比例，而非原始合成速度。
