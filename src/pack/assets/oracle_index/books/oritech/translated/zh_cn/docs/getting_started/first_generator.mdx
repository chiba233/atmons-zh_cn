它可燃烧普通熔炉燃料，生成**32 RF/t**，足以驱动你的首批加工机器运行。

一台发电机足以满足新手工坊初期需求，但您很快便会超出其承载能力。在逐步升级至更优发电机与自动化系统的过程中，请放心建造多台发电机。

一旦启用此功能，[红石炉](@oritech:powered_furnace_block)往往是一个不错的初始便利性升级。
