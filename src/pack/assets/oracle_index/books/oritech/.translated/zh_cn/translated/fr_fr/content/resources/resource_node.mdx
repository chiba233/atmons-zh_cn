资源节点遍布世界各处，以集群形式出现在基岩层上方。主世界所有类型矿石均有对应的资源节点。它们通常被一小片[原油](../resources/crude_oil)覆盖。

资源矿脉只能使用[基岩层钻机](../interaction/deepdrill)开采。

在地表，资源矿脉集群的位置可通过[矿石簇](../resources/ore_boulder)识别。矿石方块本身亦指示该集群中所含矿石类型。
