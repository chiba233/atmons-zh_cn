# 稳定模块

稳定模块可以装在 [力场投影仪](@mffs:projector) 上，把力场结晶成实体形态。
投影仪不再生成那种一关就消失的能量屏障，而是用玩家提供的真实方块把力场替换掉。

这样一来，稳定模块就能把力场图样原样造成实体建筑，投影仪关掉之后它依然留在那里。
因为是用真方块搭的，它的坚固程度就取决于所用的方块。不过只要投影仪供能充足、替换方块管够，
结构被破坏时它会不断把缺口补回来。

稳定（转置）过程比普通投影更耗 Fortron、也更慢；但要是与投影仪的 [自定义模式](@mffs:custom_mode)
配合起来用，能玩出来的花样几乎没有上限。

举个例子：玩家可以造一座每次被 [苦力怕](@creeper) 炸开都会自动修好的建筑。
在投影仪里加入 [速度模块](@mffs:speed_module)，可以同时稳定多个方块。

## 用法

- 在力场投影仪旁边（任意一面）放一个箱子，确保里面有搭建力场所需的方块。
- 把力场稳定模块放进投影仪的矩阵槽，按需要设好力场，然后激活投影仪。
- 投影仪会按方块在相邻箱子里出现的顺序取用。如果箱子里混着好几种方块，造出来的结构也会是混着的。

## 自定义模式下的用法

与力场投影仪的其他模式不同，自定义模式物品记下的是每个方块的精确位置和类型，
因此 [自定义模式](@mffs:custom_mode) 的稳定过程不太一样。

它不会按出现顺序取方块、再随便摆到某处，而是只取与原图样匹配的方块类型，
每一个都按其类型和位置精确放置。如果投影仪用完了复刻图样所需的某种方块，它会暂停，直到你补上为止。
