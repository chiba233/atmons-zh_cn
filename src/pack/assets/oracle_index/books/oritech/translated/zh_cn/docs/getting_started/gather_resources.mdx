title: 收集资源

你的首批Oritech机器结构简单，但仍需稳定的基础矿石库存。

请先寻找暴露的洞穴矿石、地表矿石巨石，或规划一条优质采矿路线。前期最重要的材料是**铜、铁、煤炭与镍**。

镍尤为重要，因其出现在多项早期机器与合金配方中。红石、金以及少量钻石也将迅速变得实用，因此采矿时切勿忽视它们。

同时请留意紫晶洞。当进度路径推进至辐水晶生产阶段时，您将需要获取紫晶母岩。
