资源节点遍布世界各处，集中分布于基岩层上方。它们涵盖主世界所有矿石类型，且通常被一小片[原油团](../resources/crude_oil)覆盖。


资源节点仅能通过[基岩层钻机](../interaction/deepdrill)开采。

在地表，资源节点集群的位置可通过[ore boulder](../resources/ore_boulder)识别。
矿石巨石亦可指示该集群中所含矿石种类。
