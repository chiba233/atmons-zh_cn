---
title: 矿石破碎
icon: oritech:platinum_clump
---

[粉碎工厂](../processing/fragment_forge)可提升矿石处理效率。当矿石在粉碎工厂中被处理时，会被破碎为矿渣与小矿渣。

九个小矿团可合成一个矿团。这些矿团随后可送入[离心机](../processing/centrifuge)中，转化为粉尘与微尘，进而于熔炉中冶炼。


您可将原生矿石投入碎片熔炉，但对部分矿石而言，使用附魔“精准采集”的镐挖掘矿石方块并直接投入熔炉，可获得更优结果。

碎片熔炉与离心机同样可产出次级矿石。例如，加工[niklu](../resources/nickel)可产出镍，同时还可能产出少量[platyny](../resources/platinum)。
