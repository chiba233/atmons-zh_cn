# All the Mons 1.2.0 上，各类生成物的**实测张数/份数**。
#
# 这些数字不是拍出来的下限，是拿本版整合包跑一遍生成器量出来的基线。
# build_dist.sh 用它做「不许回退」的判据：低于基线就红。
#
# 为什么不再写死一个数：原先的 1300 / 200 是**上一个整合包**的量级。
# 两个包的模组集合不同，同一套映射能落地的份数本来就不一样，
# 拿旧包的数字卡新包，红的是「模组换了」，不是「汉化少了」——
# 那种红没有信息量，只会逼人去调数字，闸就废了。
#
# 换整合包版本时要重新量一次，并且**必须在这里留下改动记录**，
# 这样任何一次下调都在 git 里看得见，而不是悄悄改个魔数。
#
# ── 导览书（patchouli_books / ae2guide / oracle-index 的输出文件数）──────

#     与原文相同没写 0 个；该版本没有的跳过 713 个
# 也就是说译文这一侧是满的，一条没漏；1294 这个数是「本版有哪些模组」
# 决定的，跟翻译质量无关。那 713 份是上一个整合包有、这一版没有的模组的书。
