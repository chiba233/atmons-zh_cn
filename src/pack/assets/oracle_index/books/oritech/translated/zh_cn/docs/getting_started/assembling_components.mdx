您的下一步重要进展是建造一台[铸造台](@oritech:assembler_block)与一台[离心机](@oritech:centrifuge_block)。

组装机比手动合成更高效地制作多种组件，且若干无法手工正确制作的部件必须依赖组装机。

离心机负责处理整个科技树所依赖的资源转换，包括矿团处理、碳纤维生产，以及在安装合适插件后进行的后续流体加工。


这两台机器均需RF能源，且在您理解[addons]($ADDON_CONCEPTS)后，其用途将大幅提升。
