在进阶至奥瑞泰克（Oritech）更强大的机器之前，您需要**通量水晶**。

通常可通过将[末影激光器](@oritech:laser_arm_block)与[目标标识器](@oritech:target_designator)对准紫晶团簇来获取。

激光路径的重要性不仅限于辐水晶。后续阶段，激光还可为[原子锻造器](@oritech:atomic_forge_block)等机器供能，支持无线能量传输，并助力模组部分顶级加工流程的实现。

在完成激光装置搭建后，你已步入Oritech的全新阶段——机器不再孤立运作，而是开始组成系统。
