# 远程控制器

远程控制器是一件了不起的装置，代表着远程配置技术的最前沿。
它不只是让你远程开关一台 MFFS 机器，而是直接把机器的界面本身送到你面前。

<PrefabObtaining />

## 运作方式

激活后，远程控制器会与它所控制的机器建立一条双向物质流。
这样玩家不仅能访问机器的全部配置项，还能存取其中的物品——就像站在机器旁边一样。

远程控制器不需要充电，它直接从附近同频率的 MFFS 机器取电。因此 Fortron 不足时它无法工作。

## 用法

- 打开要控制的那台 MFFS 机器的界面，把控制器放进它的频率槽，以设定控制器的频率
- 潜行右键点击目标机器，把控制器与它绑定。控制器会显示所绑定机器的名称和坐标
- 走远之后右键使用控制器，即可打开那台机器的界面
