# 生物识别器

生物识别器是 MFFS 机器家族的一员。它读取玩家散发的生物特征，据此决定玩家与力场、MFFS 机器交互时拥有哪些权限。

举例来说，它可以让某个玩家穿过启动中的力场，或者让他不受 [干涉矩阵](@mffs:interdiction_matrix) 的影响。

## 用法

要让生物识别器认得某个玩家，打开它的界面，把一张 [识别卡](@mffs:id_card) 放进左上角标着「权限」的槽位。
如果这张 [识别卡](@mffs:id_card) 还是空白、没有绑定过，你可以手持它潜行右键点击自己来绑定给自己，
也可以潜行右键点击其他玩家来绑定给他。

接着在界面右侧切换按钮，设定你希望这名玩家拥有哪些权限。

各按钮对应的权限：
- **穿越**：允许玩家潜行穿过力场。
- **修改方块**：允许玩家在干涉矩阵保护的范围内放置或破坏方块。
- **访问方块**：允许玩家在矩阵作用范围内打开任何东西的界面。
- **配置**：允许玩家配置生物识别器、修改用户权限。
- **无视防御**：允许玩家无视干涉矩阵施加的限制。
- **免于没收**：让玩家不受干涉矩阵的没收效果影响。
- **远程控制**：允许玩家对与该识别器联动的机器使用远程控制器。

权限设好之后，把那张卡移到界面底部 9 个槽位中的任意一个，整个流程就完成了。
想把自己设为某台生物识别器的主人，就把绑定到你自己的 [识别卡](@mffs:id_card) 放进标着「主人」的槽位。

生物识别器的主人自动拥有全部权限。给它红石信号，或者点击界面左上角的红石火把按钮，即可启用。
启用后生物识别器会亮起并开始生效。

## 注意

穿越力场时必须一直保持潜行，直到完全离开力场屏障为止，否则会被杀死。

生物识别器工作期间无法取出 [识别卡](@mffs:id_card)。

穿过力场可能会带来短暂的反胃 IV。

创造模式的玩家永远可以穿越力场。
